# Tetris

브라우저에서 바로 실행 가능한 클래식 테트리스. 의존성 0개, 빌드 없음, 단일 페이지 정적 자산.

## 라이브 데모

🎮 **(배포 URL은 GitHub Pages 활성화 후 업데이트)**

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 (랜딩) → PLAY → /play.html (게임)
```

또는 `index.html` 파일을 브라우저로 직접 열어도 동작합니다.

## 구성

| 파일 | 역할 |
|------|------|
| `index.html` | 랜딩(인트로) 페이지 — 진입점 |
| `play.html` | 게임 본문 (Canvas + 사이드 패널) |
| `style.css` | 게임 화면 다크 테마 스타일 |
| `script.js` | 게임 로직 (Vanilla JS) |

## 조작

| 키 | 동작 |
|----|------|
| ← → | 좌우 이동 |
| ↓ | 소프트 드롭 |
| ↑ | 회전 |
| Space | 하드 드롭 |
| P | 일시정지 |
| R | 재시작 |

## 핵심 기능

- 10 × 20 보드, 표준 7-bag 무작위 분배
- 4방향 회전 + 벽 킥(`-2, -1, +1, +2` 오프셋)
- 고스트 피스로 낙하 지점 미리보기
- 라인 클리어 점수 (1줄 100 · 2줄 300 · 3줄 500 · 4줄 800, 레벨 배수)
- 10라인마다 레벨업, 낙하 속도 가속
